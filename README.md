# Phantomgram

Неофициальный клиент Telegram для **iOS** и **Linux** на [TDLib](https://github.com/tdlib/td) и Flutter.
Одна кодовая база, официальный протокол Telegram, ваши ключи API.

> Phantomgram не связан с Telegram. Это сторонний клиент по правилам
> [Telegram API](https://core.telegram.org/api/terms).

## Версия 0.1 — что уже есть

| | Функция | Как работает |
|---|---|---|
| 👻 | **Призрачный режим** | Не отправляет «в сети», «печатает…» и отметки о прочтении. Сразу уходит в офлайн после отправки сообщения. Включается значком глаза на главном экране; прочитать вручную — меню чата |
| 🗑 | **Удалённые сообщения** | Остаются в чате с красной рамкой и пометкой «удалено». Общий журнал: Настройки → Удалённые и изменённые |
| ✏️ | **История правок** | Все версии отредактированного сообщения: долгое нажатие → «История правок» |
| 📌 | **Безлимитные закрепы** | Долгое нажатие на чат → «Закрепить локально». Без лимита Telegram, но только на этом устройстве |
| 🛡 | **Спам сразу в архив** | Серверная настройка Telegram + локальные правила: стоп-слова, ссылки от незнакомцев, SCAM/FAKE, без аватарки. Журнал с кнопкой «Не спам». Отдельно — скрытие сообщений по словам во всех чатах |
| 🌐 | **Авто-MTProxy** | Собирает прокси из ваших источников (сайты со списками и @каналы), пингует каждый 3 раза, держит **топ-5** по задержке/стабильности, **пересчитывает каждый час**, при обрыве переключается на следующий |
| 🎨 | **Оформление** | Акцентный цвет, цвет своих сообщений, скругление пузырей, размер текста, компактный режим, AMOLED, время с секундами |
| 🔑 | Вход | Номер + код, облачный пароль, e-mail-код, регистрация, вход по QR |

Раздел **TikTok** в настройках зарезервирован под следующую версию.

### Честно об ограничениях

- Удалённое сохраняется, только если сообщение успело дойти до устройства (клиент был запущен или чат открывался).
- Telegram сам показывает вас «в сети» в момент отправки сообщения — клиент сразу отправляет «не в сети», но мгновение онлайна всё же бывает.
- Скорость MTProxy оценивается по пингу, разбросу и потерям: скачать тестовый файл через MTProxy в обход Telegram невозможно.
- Локальные закрепы не синхронизируются между устройствами.
- В v0.1 медиа показываются подписью («🖼 Фото …»), без просмотра.

## Сборка

Нужен свой `api_id`/`api_hash` с [my.telegram.org](https://my.telegram.org) → API development tools.
Их можно ввести при первом запуске или вшить при сборке:
`--dart-define=TG_API_ID=123456 --dart-define=TG_API_HASH=0123…`.

### Linux

```bash
sudo apt install clang cmake ninja-build pkg-config gperf libgtk-3-dev liblzma-dev libssl-dev zlib1g-dev
scripts/build_tdlib_linux.sh          # ~20–40 минут, один раз
flutter build linux --release
./build/linux/x64/release/bundle/phantomgram
```

### iOS (на Mac)

```bash
brew install gperf cmake coreutils
scripts/build_tdlib_ios.sh            # долго: OpenSSL + TDLib для iPhone и симулятора
flutter build ios --release           # или --no-codesign для установки через AltStore/Sideloadly
```

### Готовые сборки

GitHub Actions собирает всё сам:

- **Build Linux** — при каждом push в `main`: артефакт `phantomgram-linux-x64.tar.gz`.
- **Build iOS (unsigned)** — вручную (Actions → Run workflow) или по тегу `v*`: `Phantomgram-unsigned.ipa`
  для установки через AltStore / Sideloadly / TrollStore. Запускается вручную, потому что минуты macOS дорогие.

## Устройство проекта

```
lib/
  core/        td_client (async-обёртка TDLib), settings, services
  features/
    auth/      вход
    chats/     список чатов, локальные закрепы
    chat/      переписка, пузыри, история правок
    ghost/     призрачный режим
    archive/   журнал удалённых и правок (JSONL на чат)
    antispam/  правила + сервис
    proxy/     парсер ссылок, ранжирование, менеджер ротации
    theme/     тема и редактор
packages/tdjson_native/   dart:ffi к libtdjson + упаковка .so / .xcframework
scripts/                  сборка TDLib (версия зафиксирована в scripts/TDLIB_COMMIT)
```

Тесты: `flutter test`. Смоук-тест с настоящей TDLib:
`TDJSON_PATH=packages/tdjson_native/prebuilt/linux/libtdjson.so flutter test test/tdlib_smoke_test.dart`.
